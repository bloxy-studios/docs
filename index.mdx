groot is a scaffolding CLI that plants a [Turborepo](https://turborepo.com) monorepo and grows it with the apps you pick — across five slots: web, mobile, desktop, API, and backend. Instead of maintaining frozen templates, groot orchestrates each framework's official generator — `create-next-app`, `sv create`, `create-expo-app`, `create-tauri-app`, `create-hono`, and more — then stitches the results into one coherent bun workspace with shared configs, consistent dev ports, and a single lockfile.

## What groot builds

Run `groot init my-app` and answer a few prompts. groot plants your Turborepo trunk, runs each framework's official generator, and stitches everything together:

| Slot | Frameworks | Location |
|------|-----------|----------|
| 🌐 Web | Next.js · SvelteKit | `apps/web` |
| 📱 Mobile | Expo | `apps/mobile` |
| 🖥️ Desktop | Tauri · Electron | `apps/desktop` |
| ⚡ API | Elysia · Hono | `apps/api` |
| 🗄️ Backend | Convex | `packages/backend` |

## How it works

<Steps>
  <Step title="Pick your stack">
    Answer interactive prompts (or pass flags) to select a web app, mobile app, desktop app, API, and backend. Skip any slot you don't need.
  </Step>
  <Step title="groot generates">
    groot runs each framework's official generator with pinned, non-interactive flags. No vendored templates means scaffolds never rot.
  </Step>
  <Step title="groot stitches">
    The output is patched into monorepo shape: workspace globs, `@repo/*` package names, shared TypeScript config, deterministic dev ports, and one root lockfile.
  </Step>
  <Step title="You're ready">
    `cd my-app && bun run dev` — every app starts with one Turborepo command.
  </Step>
</Steps>

<Tip>
  Run `groot init my-app --dry-run --json` to preview exactly what will be scaffolded before writing a single file.
</Tip>
